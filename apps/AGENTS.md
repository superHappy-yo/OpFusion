# apps：装配层 AI 规则

先读根 AGENTS、架构依赖规则和本目录 README，再读本次使用的公共契约。

- 你负责依赖装配、配置进入、阶段调用、全局预算和不可变快照的反馈接纳/回退。
- 默认仅能写 `apps/` 内实现、测试和说明；根配置、contracts、其他模块、所有 AGENTS/CLAUDE 及治理文件默认只读。
- 可以导入各模块公开入口并显式注入实现；不能导入其内部对象、复制算法或直接修改内部缓存。
- apps 是 composition root，不是“拥有整个仓库”的授权。跨模块需求必须列出已获授权路径并分配限定范围的子任务。
- 不改变候选、计划、测量记录的原始身份和版本；不把新成本写回正在运行的计划。
- runtime 环境失配或失败由这里决定停止/重新规划；worker 不应私自切换实现。
- 当前没有可运行入口。首次实现前以 M1 真实工具链为准，不虚构启动/测试命令。
- 验证固定快照、预算耗尽、失败回退、模块替换和完整数值/输出交付；完成前检查全部变更路径。
