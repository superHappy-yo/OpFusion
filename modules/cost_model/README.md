# cost_model — 特征、成本预测与校准

状态：规格目录，尚无实现。修改前阅读本目录 [AGENTS.md](AGENTS.md)。

## 唯一责任

构建语义/边界/实现/硬件条件特征，预测完整区域代价、输出不确定性，并依据独立观测校准。

| 项目 | 契约 |
|---|---|
| 输入 | 候选、接口、设备 profile、执行条件、已有 MeasurementRecord |
| 输出 | 带条件和来源的预测 CostRecord、模型版本及校准请求 |
| 允许依赖 | 仅依赖 contracts 的公开类型和端口；其他能力由 apps 注入。禁止导入邻居模块的具体实现。 |
| 不负责 | 禁止直接操作硬件、生成融合划分、调度任务、替换观测真值；不得偷用留出标签或把未知值当零。 |
