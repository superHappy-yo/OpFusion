# planner — 异构映射与事件/内存规划

状态：规格目录，尚无实现。修改前阅读本目录 [AGENTS.md](AGENTS.md)。

## 唯一责任

在固定候选快照和部署环境下，联合选择完整划分、实现、适配器、设备、事件顺序及物理缓冲。

| 项目 | 契约 |
|---|---|
| 输入 | CandidateSnapshot、DeploymentContext、兼容关系和资源规则 |
| 输出 | ExecutionPlan、计划检查报告或明确的失败/未找到原因 |
| 允许依赖 | 仅依赖 contracts 的公开类型和端口；其他能力由 apps 注入。禁止导入邻居模块的具体实现。 |
| 不负责 | 禁止编译、设备执行、改候选时延、重新定义语义、静默生成新实现；不得把局部合法当成完整计划可行。 |

## 未来内部组织

按真实任务增加 `src/`、`tests/` 和 `docs/`；接口变更建议放 `proposals/`。目录是所有权边界，不要求独立发布包或独立服务。

同一 Conv 图在 X 位于 CPU 或 GPU、Y 要求回主机时，必须分别计入适配和交付成本。

## 验收重点

初始驻留和最终输出位置；Join 兼容性；跨主机依赖；输出缓冲启动前分配；全程工作区预留；重复副本不重复计费。

当前没有测试/启动命令。第一次实现时记录真实环境、命令与结果，不能把这里的验收目标写成已通过事实。
