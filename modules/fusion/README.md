# fusion — 区域构造与候选图搜索

状态：规格目录，尚无实现。修改前阅读本目录 [AGENTS.md](AGENTS.md)。

## 唯一责任

从原始图推导边界，生成合法完整划分，查询已有实现与代价，按有限预算保留候选图。

| 项目 | 契约 |
|---|---|
| 输入 | GraphSpec、能力/实现/成本端口、候选和测量预算 |
| 输出 | 不可变 CandidateSnapshot、接口及兼容关系引用、搜索轨迹 |
| 允许依赖 | 仅依赖 contracts 的公开类型和端口；其他能力由 apps 注入。禁止导入邻居模块的具体实现。 |
| 不负责 | 禁止最终设备映射、开始时刻选择、RPC 或执行；不搜索任意 tile/线程/内核结构；不在原图中加入设备节点。 |

## 未来内部组织

按真实任务增加 `src/`、`tests/` 和 `docs/`；接口变更建议放 `proposals/`。目录是所有权边界，不要求独立发布包或独立服务。

输出 Π0、Π12、Π23、Π123 中有依据的备选；只有后端支持且验证符合接口，才登记相应可执行候选。

## 验收重点

完整覆盖且互斥、商图无环、外部输出保留、参考候选；pending 不伪装 verified；同候选池/预算测试保留策略。

当前没有测试/启动命令。第一次实现时记录真实环境、命令与结果，不能把这里的验收目标写成已通过事实。
