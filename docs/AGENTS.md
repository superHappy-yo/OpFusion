# docs：架构与治理文档规则

遵守根 AGENTS。这里只维护任务明确涉及的架构、协作、路线和验证说明；编辑文档不自动授权修改业务模块。

- `architecture/` 是全仓设计约定；变化需说明受影响模块和迁移，不以文档重写隐含改变实现授权。
- `ai/` 的规则、任务模板与 scopes.json 是治理资料，普通模块任务只读。不得自改白名单以通过范围审查。
- `verification/` 只记录真实完成的检查；计划、未实现门禁、模拟和实测分别标记。
- 公开文档不包含本机绝对路径、凭据、用户原始论文或不可分享的原始数据。
- 链接用仓库相对路径；未实现的命令和 API 明确标注，禁止写成已可用。
